# Application and Testing Contribution

This application contribution includes the implementation of the three-tier/MVC software system and its testing evidence. The work comprises the responsive HTML/CSS view layer, Flask controllers, reusable business services, SQLAlchemy database models, user authentication, catalogue search, shopping cart, checkout, inventory control, order management, administrator functions, automated testing, and Vercel deployment configuration.

The implementation maps directly to the assignment criteria for Model, View and Control, requirement verification, detailed design, test planning and evidence of testing.
